# Yoonjin Shin Portfolio

A responsive portfolio website based on three Figma designs. The home page links to the MEALING and LuggEasy Scale case studies.

## Pages

- `index.html` — Portfolio home
- `mealing.html` — MEALING case study
- `luggage.html` — LuggEasy Scale case study

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.
